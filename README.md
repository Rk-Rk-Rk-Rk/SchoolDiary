# Информационная система «Электронный дневник» (Версия 1.0)

Настольное приложение для общеобразовательных учреждений и учебных заведений СПО, предназначенное для автоматизации учета успеваемости, ведения классного журнала и статистического анализа учебного процесса.

---

## 📌 Описание системы
Программа представляет собой полнофункциональную базовую версию информационной системы **«Электронный дневник»** с локальной базой данных **Microsoft Access (`.accdb`)** и модулем авторизации пользователей с разграничением прав доступа.

---

## 🛠 Технологический стек
* **Среда разработки:** Microsoft Visual Studio (2022 / 2026)
* **Язык программирования:** C#
* **Платформа:** Windows Forms (.NET 8.0-windows / .NET Desktop)
* **СУБД:** Microsoft Access (`SchoolDiary.accdb`)
* **Провайдер данных:** Microsoft Access Database Engine OLE DB (`Microsoft.ACE.OLEDB.12.0` / `16.0`) через пакет `System.Data.OleDb`

---

## 🔑 Учетные записи для входа в систему

| Логин | Пароль | ФИО / Должность | Роль в системе | Права доступа |
| :--- | :--- | :--- | :--- | :--- |
| **`admin`** | `admin123` | Администратор системы | Администратор | Полный доступ: управление журналом, списком учащихся, аналитикой |
| **`teacher`** | `teacher123` | Шадрина А. Ю. (Преподаватель) | Учитель | Выставление, изменение и удаление оценок, просмотр учащихся, аналитика |
| **`student`** | `12345` | Алексеев Артем (Ученик) | Ученик | Просмотр оценок и успеваемости (режим чтения) |

## 🚀 Функциональные возможности

1. **Модуль авторизации:**
   * Проверка подлинности пользователей по базе данных Access.
   * Безопасный ввод пароля (маскирование).
   * Разграничение прав доступа в зависимости от роли (Администратор, Учитель, Ученик).

2. **Журнал успеваемости:**
   * Просмотр оценок в лаконичном строгом стиле.
   * Фильтрация записей по учащемуся и предмету.
   * Выставление, редактирование и удаление оценок с сохранением в базе данных Access.

3. **Реестр учащихся:**
   * Список учащихся учебной группы.
   * Поиск по фамилии прямо во время ввода.
   * Добавление, редактирование и удаление данных.

## 💻 Запуск и отладка в Visual Studio

1. Откройте файл **`SchoolDiary.sln`** в Visual Studio.
2. Выберите конфигурацию **`Debug | x64`** (или `Any CPU`).
3. Нажмите клавишу **`F5`** для запуска.
